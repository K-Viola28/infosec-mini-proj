# Password Strength Checker (Python)

## Description

A command-line tool that evaluates a password using its length and the
presence of lowercase letters, uppercase letters, digits, and special
characters.

The password is classified as **Weak**, **Moderate**, or **Strong**. Password
input is hidden while it is entered.

## Run

```bash
python password_checker.py
```

## Concepts

- Password security
- Authentication
- Python string validation
